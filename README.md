# THE NIGHT UNC

2D action platformer (Godot 4, Windows-first) for GuaraGameJam2026. Two playable stages: Yeral — The Spoilerman and his true second form, Glizzy Gobler, followed by Bichema's World — the Evil Genius, the alpha and the omega.

## Run and debug on Windows

1. Install Godot 4.x (standard build, not .NET) from https://godotengine.org/download/windows/ or `winget install GodotEngine.GodotEngine`. Unzip it anywhere; no installer is needed.
2. Clone the repo: `git clone https://github.com/Ragnorus/GuaraGameJam2026.git`.
3. Start Godot, click **Import**, select `project.godot` in the repo folder, then **Import & Edit**.
4. Press **F5** (Play) to open the main menu (Start Game, Level Select, Settings, Game Info). Press **F6** to run the currently open scene.
5. Reach the far end of a stage and defeat its boss. Depleting Yeral's first health bar transforms him into Glizzy Gobler with a fresh health pool; he cannot take damage during the transformation. Defeat the second form and wait for his collapse, then Night Unc receives Yeral's power in a Mega Man-inspired energy-absorption cinematic. His original sprites float amid green energy, followed by a comic bubble saying **"Dime a vel!"** with the supplied voice recording. The sequence locks gameplay, waits for the whole line even when SFX are muted, and fades into Ema's stage with Dash unlocked. Completing Ema's final form fades into the end credits, then returns to the main menu. Each stage starts with a fresh player. Press **R** while playing or after death to restart the current level; restarting either Yeral form restores the first encounter.

Debugging:
- Errors, warnings and `print()` output show in the **Output** and **Debugger** panels at the bottom of the editor. Script errors pause the game and open the failing line.
- Click the gutter left of a line number in the Script editor to set a breakpoint (red dot). When it hits, use the Debugger controls (**F10** step over, **F11** step into, **F12** continue) and inspect variables in the Stack Variables panel.
- While the game runs, the **Remote** tab in the Scene dock shows the live node tree. Select a node (for example the boss) to read or edit its properties in the Inspector.
- Use the **Debug** menu for **Visible Collision Shapes** to see hitboxes, and **Visible Navigation** if you add pathfinding.
- If scripts fail to parse, check that class names (`Player`, `BossYeral`, `BossEvilGenius`, `YeralHints`, ...) are unique. Use **Project > Reload Current Project** after adding `class_name` scripts.
- If Godot reports that a member already exists in a parent class, remove the duplicate declaration from the subclass. `Robot` uses the `sprite` member inherited from `Bug`.

## Test and preview locally

Replace `godot` below with the path to your Godot 4.5 executable if it is not on your `PATH` (for example `& "C:\Tools\Godot\Godot_v4.5.1-stable_win64.exe"`).

**Preview a level in the editor**
1. Open the project (`godot --editor --path .`) and let it finish importing. After changing anything in `assets/`, focus the editor window so it reimports.
2. Press **F5** to play from the main menu, or open `scenes/main.tscn` (Yeral) or `scenes/bichema_level.tscn` (Bichema's World) and press **F6** to run just that scene (menu settings are only loaded when you start from the main menu).
3. Yeral: clear the city guards, descend through the sewer, defeat the sergeant over the acid, ride the moving blocks up to the city, then enter the warehouse at the end of Area 5. Ema: x > 4977 in the final factory. Enable **Debug > Visible Collision Shapes** to check hitboxes.

**Preview without the editor**
- Yeral level: `godot --path . res://scenes/main.tscn`
- Bichema's World: `godot --path . res://scenes/bichema_level.tscn`

**Regenerate level art**
1. Yeral's generated tiles: `node tools/gen_assets.js` (no dependencies). Stage-two complete paintings: `python tools/slice_bichema.py`; plaza platforms: `python tools/slice_capital.py` (Pillow required).
2. Refocus the Godot editor so it reimports the PNGs, then press **F6** to preview.

**Re-slice character and prop sprites** (Yeral, robot minions, Tacoma Bros, lair props; sources in `art/sheets/`, ignored by Godot via `art/.gdignore`)
1. `node tools/slice_lair.js` writes `assets/sprites/lair`; `node tools/slice_gotham.js` cuts `art/sheets/spoiler_gotham_sheet.png` into `assets/sprites/gotham` and crops the sheet's painted skyline, unaltered, into `assets/sprites/city_bg` (preview with `node tools/preview_bg.js out.png [scrollX]`). `node tools/slice_sheets.js` writes `yeral*` and `robot*`.
2. `node tools/contact_sheet.js <group> out.png` lays a group's frames out for a quick visual check.
3. Open the project once in Godot so it creates the `.import` files for the new PNGs, and commit them.

Tacoma Bros art is preserved in `art/sheets/tacoma_bros_sheet.png`; `python assets/extract_tacoma_bros.py` (Pillow required) writes anchored Ludo/Capi combat frames, `assets/tacoma_truck_atlas.png` with idle/drive/charge/drift/spin animations in `assets/tacoma_truck_frames.tres`, and the Toyota-logo projectile from `art/sheets/tacoma_projectile_sheet.png`. Both source sheets remain unchanged.

**Headless scene smoke test** (loads the actual scene, keeps the player survivable, and damages either boss through both forms until the final animated defeat; missing transformations/bosses or a missing defeat fail within a bounded run)
- Yeral: `godot --headless --path . -s tools/smoke_test.gd -- res://scenes/main.tscn`
- Bichema's World: `godot --headless --path . -s tools/smoke_test.gd -- res://scenes/bichema_level.tscn`

Look for `SMOKE boss:` followed by `SMOKE PASS:`; success requires exactly one transformation, exactly one final defeat signal and a live-player stage clear. A non-zero exit code or any `SCRIPT ERROR` means something broke; `SMOKE FAILED:` explains explicit smoke failures. If it fails with missing class names on a fresh clone, run `godot --headless --path . --import` once first.

**Preview the Web build** (what Railway serves)
1. Export: `godot --headless --export-release "Web" build/web/index.html` (needs the Web export templates).
2. Serve it: `python -m http.server 8080 --directory build/web`, then open http://localhost:8080 (browsers won't run it from `file://`).

## Level layout and mobs

- Jumpable platforms use a consistent pale-gold landing edge with dark backing and short end brackets. Markers match the exact collision width/top on fixed and moving platforms, the plaza bridge, and painted pub/factory ledges; decorative props are not marked. Original textures, jump heights and one-way collision behavior are unchanged. Check with `godot --headless --path . --fixed-fps 60 --script res://tests/platform_visibility.gd`.
- Readability approach: [The Level Design Book](https://book.leveldesignbook.com/process/blockout) emphasizes metrics, wayfinding and playtesting; [Game Accessibility Guidelines](https://gameaccessibilityguidelines.com/provide-high-contrast-between-text-ui-and-background/) recommends outlines/backing for separation, while its [color guidance](https://gameaccessibilityguidelines.com/ensure-no-essential-information-is-conveyed-by-a-fixed-colour-alone/) recommends redundant shape/pattern cues. Applied here as static, collision-aligned top edges and brackets rather than color-only recoloring or flashing highlights. The UI contrast guidance informs separation, not a claim that a UI contrast threshold validates all scenery.

- Yeral's route (`scripts/yeral_route.gd`) follows the five-area sketch: **1 City approach -> 2 Sewer descent -> 3 Sergeant room -> 4 Sewer ascent -> 5 City warehouse entrance -> warehouse boss room**. Only Areas 1 and 5 use the supplied city painting; the sewer and warehouse have generated original environments. Each room has its own camera limits and enemies; exits wait for the active room's guards/sergeant.
- The sergeant room has exactly three fixed, deterministic platforms over an animated lethal green acid pit. No random platforms are generated. Acid kills regardless of remaining HP or damage invulnerability.
- The **Football Sergeant** (`scripts/sergeant.gd`, art from the supplied `art/sheets/football_sergeant_sheet.png`) guards Area 3. He leaps between the fixed blocks, football-charges to shove you toward the acid, punches you into a bounce, and screams a sound wave that only damages and stuns (stars circle your head). He never stands still: he stalks you along his block or paces it, and attacks faster when you are close. If a charge misses and carries him off a block, he falls; the acid can't hurt him, so he splashes out and jumps (dedicated jump pose) back onto the nearest block and keeps fighting. A miss can also land him on a lower block or the entrance bank. At 50% health he transforms into his red **roid rage** form with faster, stronger attacks, shouting his line in the same comic bubble Yeral uses. Entering Area 3 shows a timed "BEWARE! NEW ENEMY!" stage message. Test: `tests/sergeant_actions.gd`.
- Area 4 has a horizontal moving block, a safe middle ledge and a vertical moving block leading to the raised sewer exit. The player must reach the upper exit; walking along the bottom cannot skip the challenge. Room changes animate the sewer entry/exit with a short fade.
- **Level 1 upgrades:** entering each new area sets a session checkpoint. Death or Restart Level resumes at that area's safe entrance with fresh health; restarting at the warehouse replays Yeral's protected first-form intro. Start Game / Level Select clears checkpoint progress; closing the game does not save it. Score still resets to the level-start value on retries.
- Jump height responds to how long jump is held, with a 0.12-second input buffer before landing. The existing double jump still allows jumping after walking off a ledge (rather than replacing this more generous behavior with a restrictive coyote timer). Held-jump height and 10 maximum HP are unchanged.
- Defeated ordinary enemies can drop temporary coins or small Medalla cans: a hurt player has a 22% heal / 28% coin / 50% nothing roll; at full health it is 50% coin / 50% nothing. Small cans heal 2 HP; fixed cans heal 4. Drops expire after eight seconds and blink during the last two.
- Optional **turrets** use the supplied neon-sewer art and matching green bolts, telegraph for 0.6 seconds, then fire slow horizontal shots: first on safe city ground, then at the upper sewer exit. A **hopper** robot in the descent crouches before jumping toward the player. Its separate gold head marker leaves the supplied sprite colors intact.
- Area 4 adds a swooping flyer to clear while navigating the moving blocks, plus the optional exit turret. A fixed Medalla on the safe entrance bank provides a breather; the middle ledge remains safe geometry. The Area 5 Medalla and warehouse **GET READY!** caption provide preparation before the boss.
- Defeating the Football Sergeant permanently unlocks **Shield Burst** (Q / LT) across both stages: a 190-pixel ring deals 3 damage, clears nearby enemy projectiles and scream waves, and grants 0.6 seconds of damage invulnerability. Six-second cooldown, shown in the HUD. It does not prevent lethal acid death, damage inactive-room enemies, or work while dead, stunned, or in a cinematic.
- Ordinary hits give a short recoil and red damage flash; the sergeant's stronger directional knockback and shove-free scream remain distinct. Two optional high ledges in the city areas each hold a secret trio of coins.
- Upgrade regression: `godot --headless --path . --fixed-fps 60 --script res://tests/level1_upgrades.gd` covers jump height/buffering, loot/healing/expiry, enemy variety, shield unlock/range/locks/cooldown, damage feedback, optional guards, and checkpoint death/restart including the boss intro.

Muwahahahahahaha!!!** The supplied voice plays once; movement, attacks, summons, recall, dash and ultimate are locked until the voice/cinematic finishes. The boss remains inactive and untargetable during the introduction. Pause and restart remain available.

## Deploy to Railway

Railway's default builder (Railpack) can't build Godot projects, so the repo ships a `Dockerfile` and `railway.json` that Railway uses instead:

1. The Dockerfile downloads headless Godot 4.5.1 plus its export templates and exports the **Web** preset from `export_presets.cfg` (single-threaded, Compatibility renderer, so no special headers are needed).
2. The static export is served by nginx on Railway's `$PORT` (`nginx.conf.template`).

To deploy: create a Railway project from this GitHub repo and deploy; it picks up `railway.json` automatically. Generate a public domain under Settings > Networking.

To export locally, use a standard (non-.NET) Godot 4.5 editor with the web export templates installed: `godot --headless --export-release "Web" build/web/index.html`, then serve `build/web` over HTTP (browsers won't run it from `file://`). The .NET editor build cannot export to Web.

The generated forest-green, toxic-lime, and gold pixel-art level assets in `assets/` are produced by `node tools/gen_assets.js` (no dependencies). Bichema's World uses `python tools/slice_bichema.py` to validate/copy its complete room paintings, `python tools/slice_capital.py` for plaza platforms, and `python assets/extract_bichema.py` for both boss forms and minion atlases. Original art remains in `art/sheets/`; let Godot reimport after rebuilding. The older Evil Genius sheet is still the source of the lawyer weakness cameo.
